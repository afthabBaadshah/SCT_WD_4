# ✅ Simple Todo List

A **beautiful and beginner-friendly Todo List** app made with **HTML, CSS, and JavaScript**.  
It allows you to **add**, **edit**, **delete**, and **mark tasks as complete**, with all data **saved automatically using localStorage**.

---

## ✨ Features

- ➕ **Add new todos** easily  
- ✏️ **Edit tasks** by double-clicking  
- ✅ **Mark tasks as completed** using checkboxes  
- ❌ **Delete tasks** with a single click  
- 💾 **Auto-save using localStorage** (tasks stay even after reloading)
- 💅 **Modern UI** with glass effect, gradient background, and soft shadows
- 📱 **Responsive design** — works perfectly on mobile and desktop

---

## 🧩 Tech Stack

- **HTML5** – structure  
- **CSS3** – design, layout, and animation  
- **Vanilla JavaScript (ES6)** – logic, DOM manipulation, localStorage
